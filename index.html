Redwood Agent

Redwood Agent is a private home-automation app used by a single household. It is not a public service and does not accept sign-ups.

With the owner's explicit consent through Google sign-in, it reads data from the owner's own smart-home devices (for example, a Nest thermostat's mode, setpoints, temperature, humidity and heating/cooling status) and stores it on a server the owner controls, to analyze the home's heating and cooling efficiency.
